## 最值得先读

### 1. [OpenSkillRisk: Benchmarking Agent Safety When Using Real-World Risky Third-Party Skills](https://arxiv.org/abs/2607.20121)

- **方向**：Agent safety、第三方 skills、执行边界。
- **作者主张**：从公开 skill marketplace 收集 263 个风险 skill，覆盖 7 类威胁；测试 3 个 CLI agent framework 和 13 个 LLM。即使最安全配置仍在约 17% 的案例中执行不安全动作。
- **为什么重要**：风险对象不是恶意 prompt，而是“看似正常、执行时才暴露风险”的真实 skill，直接触及开放 Agent 生态的供应链安全。
- **初筛疑问**：需要核查 skill 采样偏差、sandbox 与真实系统的差距，以及“unsafe action”的标注与严重度分层。

### 2. [Information Discernment in Large Language Models](https://arxiv.org/abs/2607.19355)

- **方向**：外部信息采信、搜索增强、alignment。
- **作者主张**：提出 Learn2Discern；在 13 个模型、约 67 万次 trial 上区分 source discernment 与 truth discernment，并用预注册用户研究（n=299）验证规范性假设。模型在两种 discernment 上整体接近随机，更依赖来源知名度而非可靠性。
- **为什么重要**：把“模型会不会使用检索结果”细化成“是否按来源质量和事实方向合理更新”，比最终答案准确率更接近真实搜索 Agent 的风险。
- **初筛疑问**：需要检查 ground truth 构造、先验估计方式，以及不同任务分布是否会改变 near-chance 结论。

### 3. [FineServe: A Fine-Grained Dataset and Characterization of Global LLM Serving Workloads](https://arxiv.org/abs/2607.19349)

- **方向**：LLM serving、AI Infra、workload characterization。
- **作者主张**：发布来自全球商业 marketplace 的真实多模型 serving workload 数据及生成器，并观察到模型架构、规模和任务意图对应不同的到达与 token 波动模式。
- **为什么重要**：如果数据覆盖真实请求异质性，它可替代常见的代理 trace，用于更可信地评估 routing、scheduling 与 capacity planning。
- **初筛疑问**：需要核查数据匿名化、采样周期、marketplace 代表性、模型混合分布和数据许可。

### 4. [Building Fast, Evaluating Slow: Pipeline Choices Dominate Autointerpretability Score Variance](https://arxiv.org/abs/2607.19386)

- **方向**：mechanistic interpretability、SAE、evaluation methodology。
- **作者主张**：在 4 个自动解释指标、2 个模型和 4 类方法变化上，方法管线方差超过架构方差；fuzzing 指标在所有条件下都不可靠，top-k 特征排名也会随语料和抽样条件变化。
- **为什么重要**：它质疑跨论文 SAE 自动解释分数的可比性，并提供 variance decomposition、Stability Check 与最低报告清单。
- **初筛疑问**：模型仅覆盖 Pythia-160M 与 Apertus-8B，需要判断结论能否外推到更大模型、不同 SAE 和不同 judge。

### 5. [PRO-LONG: Programmatic Memory Enables Long-Horizon Reasoning](https://arxiv.org/abs/2607.20064)

- **方向**：Agent memory、long-horizon reasoning、ARC-AGI-3。
- **作者主张**：保留完整结构化交互日志，让 coding agent 通过程序搜索历史；在 ARC-AGI-3 public game set 上平均提升 18.0 个百分点，并比专用 harness 少用 4.2–5.8 倍 token，最高报告 76.1% pass@1。
- **为什么重要**：核心观点不是再训练 memory module，而是把长程记忆变成可查询的程序化外部状态，简单且有工程复用价值。
- **初筛疑问**：需要核查模型、工具和预算控制是否公平；摘要同时报告 Fable 5 的 97.4% best@2 与 1,750 美元成本，不能只看成功率。

## Agent 安全与可验证性

### [CrackedPDFs: A Controlled Benchmark for Hidden Prompt Injection in PDFs](https://arxiv.org/abs/2607.19396)

- 构造 29,322 份 PDF，其中 9,774 份含隐藏 prompt injection，并用 paired benign confounders、provenance split 与 shortcut audit 控制泄漏。
- 混合 detector 在 held-out test 上报告 0.960 F1；作者明确声明这不能证明真实世界鲁棒性或跨家族泛化，边界表述比较克制。

### [DocOps: A Verifiable Benchmark for Autonomous Agents in Complex Document Operations](https://arxiv.org/abs/2607.19865)

- 提出可确定性验证的复杂文档操作评测，观察到长程状态跟踪崩溃、浅层语义验证、破坏结构元数据三类失败。
- 与 PDF prompt injection 互补：前者测试输入供应链，DocOps 测试 Agent 是否能保持文档全局一致性和非破坏性。

### [Sound Probabilistic Safety Bounds for Large Language Models](https://arxiv.org/abs/2607.20286)

- 用 Clopper–Pearson confidence interval 构造 harmful-output probability 的 PAC bounds，并用潜空间特征优先探索生成树中的高风险分支。
- 值得关注的是“sound lower bound”而非普通经验 attack rate；需要精读证明假设、搜索自适应是否影响置信区间、以及极小概率事件下的样本效率。

## 推理与生成

### [SLPO: Scaling Latent Reasoning via a Surrogate Policy](https://arxiv.org/abs/2607.19691)

- 为 latent reasoning 引入 surrogate policy density 和可变步数 stopping head，使 outcome-reward RL 能用于连续/soft latent trajectory。
- 摘要报告 Pass@k 提升并能把更长 latent computation 分配给更难样本；需核查与显式 CoT 在等 FLOPs、等采样数下是否公平。

### [Multi-Mask Diffusion Language Models for Few-Step Generation](https://arxiv.org/abs/2607.19686)

- 用多个 mask state 保留 masked diffusion 的可辨识结构，同时为 consistency-style few-step generation 保留 terminal entropy；给出 closed-form ELBO 和离散 consistency distillation。
- 已标注为 COLM 2026 accepted。摘要没有给出关键速度/质量数字，值得直接看实验表再判断收益。

### [Train the Model, Not the Reader: Decodability Supervision for Verifiable Activation Explanations](https://arxiv.org/abs/2607.20379)

- 指出自然语言 activation explanation 的 reconstruction score 对单个错误主张不敏感，并展示 verbalizer 可形成 private code。
- 提出 RECAP，通过与目标模型共同训练的线性 probe 让指定内容保持可解码；方向有趣，但实验主体含 sandbox model 与 Pythia-160M，外推需要谨慎。

## 多模态与具身智能

### [Trace: A Taxonomy-Guided Environment for Multidomain Visual Reasoning](https://arxiv.org/abs/2607.19790)

- 用 scene grammar 与 executable task program 生成 1,000 类 task、277 种 scene grammar、11 个视觉域，并保留可重放 verifier trace。
- 在 64,000 个实例上做 RLVR 后，Qwen2.5-VL-3B/7B 在 24 个外部 benchmark 上宏平均提升 3.51/4.06 个百分点；需检查外部集是否与程序模板存在结构重合。

### [KineBench: Benchmarking Embodied World Models via IDM-Free Kinematic Grounding](https://arxiv.org/abs/2607.19876)

- 用视觉基础模型直接提取 6D 末端执行器 pose，避免 inverse dynamics model 带来的误差归因混淆；在 ManiSkill3 上构造 20 个操作任务和 4 级评测套件。
- 贡献主要是评测协议而非新 world model，适合作为具身视频生成论文的对照基准。

### [Robots Acquire Manipulation Skills in Seconds from a Single Human Video](https://arxiv.org/abs/2607.20033)

- HOST 从单个人类视频做 inference-time skill acquisition，摘要报告平均 29 秒获得新技能、平均成功率 62%，比 zero-shot baseline 高 45 个百分点。
- “507 倍更快、50 倍更少示范”依赖对照设定，精读时必须核查任务数量、真实机器人覆盖、失败案例和是否使用预训练任务数据。

### [Look Less, Think Faster: Joint Token-Compute Adaptation for Multimodal LLMs](https://arxiv.org/abs/2607.20357)

- SmartVL 联合控制视觉 token 数和 LLM 侧计算量，用共享预算编码与可微 latency estimator 学习跨阶段资源分配。
- 已标注为 ECCV 2026 accepted；摘要只声称更好的 accuracy–efficiency Pareto frontier，未给绝对 latency，需看硬件、batch 和 controller overhead。

## 跨论文连接

- **Agent 风险链**：`OpenSkillRisk`（第三方 skill 风险）→ `CrackedPDFs`（文档输入注入）→ `DocOps`（复杂编辑失败）→ `PRO-LONG`（长程记忆机制）。四篇可共同回答“Agent 从输入、工具到长期状态分别在哪里失效”。
- **评测可信度**：`Information Discernment`、`Building Fast, Evaluating Slow`、`KineBench` 都在拆解单一最终分数背后的误差来源，而不是只报 benchmark 增益。
- **压缩计算**：`SLPO` 压缩显式推理、`MultiMDM` 压缩生成步数、`SmartVL` 联合压缩视觉 token 与模型计算，三者适合按等 FLOPs/等 latency 重新比较。

## 今日判断

- **论文明确支持**：今日核心 AI 类别的新投稿量很大；Agent 安全与评测协议是代表作最集中的两个方向。
- **我的推断**：若只精读三篇，优先顺序是 `OpenSkillRisk`、`Information Discernment`、`Building Fast, Evaluating Slow`，因为它们最可能改变后续 Agent 与解释性实验的评测方法。
- **仍待验证**：上述论文的基线公平性、数据/代码可获得性、计算预算、统计稳定性和跨模型泛化，均不能由摘要确认。

# 交互式世界模型与主动感知

## 定义与边界

本主题关注基础模型如何在行动、观察和内部状态之间形成可交互闭环。这里的“世界模型”至少包含四个彼此可分离的问题：

1. **控制接口**：怎样把动作或意图表示成模型能可靠理解的条件？
2. **证据获取**：上下文预算有限时，模型应该在何时、何处追加观察？
3. **状态落地**：如何把视觉记录转换为显式、可运行、可干预的物理状态？
4. **长期记忆**：自回归生成怎样保持场景身份、几何和局部动力学？

本轮四篇论文分别主攻其中一层。它们都使用“world”语言，但只有 Agentic Real2Sim 输出显式 simulator state；其余主要在视频或 observation space 工作，不能直接视为物理因果模型。

## 为什么重要

单纯提高视频质量或扩大上下文窗口并不能形成可用 Agent。可交互系统还需要动作对齐、主动取证、持久状态、成本控制和可验证反馈。把这些层拆开后，才能判断一篇论文究竟改善了生成画面、任务决策、物理真实性，还是只改善了评价指标。

## 第二轮：把关键变量外部化

[[notes/papers/2026/07/23/PRO-LONG- Programmatic Memory Enables Long-Horizon Reasoning]]、[[notes/papers/2026/07/23/KineBench- Benchmarking Embodied World Models via IDM-Free Kinematic Grounding]]、[[notes/papers/2026/07/23/Robots Acquire Manipulation Skills in Seconds from a Single Human Video]] 和 [[notes/papers/2026/07/23/Look Less, Think Faster- Joint Token-Compute Adaptation for Multimodal LLMs]] 表面上分属 Agent memory、world-model evaluation、robot imitation 和 MLLM efficiency，结构上却做了同一件事：把原本隐含在权重或活动上下文里的关键变量变成外部、可访问、可核验的对象。

| 论文 | 被外部化的变量 | 访问/对齐机制 | 获得的能力 | 尚未解决的代价 |
| --- | --- | --- | --- | --- |
| PRO-LONG | 完整交互历史 | append-only log + grep/Python | 事后按问题重构长期状态，不在 write 时丢信息 | 日志线性增长；只证实结构化确定性环境 |
| KineBench | 视频中的机器人运动状态 | mask/depth/CAD pose → 6D trajectory → simulator | 把视觉生成落到可执行、可归因的 3D 运动学 | 仍依赖感知、CAD、可见夹爪，不含接触力学 |
| HOST | 新技能与执行程序 | 单个人类视频 + progress alignment + future observation cascade | 不改权重地调用、保存、检索新技能 | 巨额摊销训练；单平台；memory 扩展会误检 |
| SmartVL | 推理资源约束 | budget token + joint token/depth/width controllers | 同一模型按输入在“多看”和“多想”间分配 FLOPs | 只报告 prefill FLOPs；没有真实 latency/decode 加速 |

### 新的共同结论

- **可访问不等于放进上下文**：PRO-LONG 的完整轨迹在磁盘、HOST 的技能在视频库，系统只在当前决策需要时检索相关部分。这比无条件扩大 context 更接近可扩展 Agent memory。
- **显式中间变量改善归因**：KineBench 用 6D pose 拆开 world-model 与 extractor error；HOST 用 progress 和 future observation 拆开演示理解与 action generation；SmartVL 用 budget/token survival 拆开视觉与语言侧资源消耗。
- **“冻结模型 + 外部状态”可以避免部分遗忘，但不会消除预训练成本**：PRO-LONG 不训练，HOST 不做任务级更新，二者都避免在线改权重；然而 HOST 的 193,462 条机器人轨迹、5,847 组人机配对与 64-GPU 训练说明快速适配依赖巨额摊销先验。
- **效率结论必须统一端到端口径**：PRO-LONG 报 billed tokens，HOST 报 acquisition wall time，SmartVL 报 prefill FLOPs，KineBench 报 4×A100 约束；这些数字不能直接横比，也都没有完整覆盖训练、工具、检索、decode 与执行成本。

### 综合判断（个人推断）

一个更完整的 embodied agent 可以把这四种外部化机制串成闭环：HOST 类视频提供新技能程序，PRO-LONG 类事件日志保存执行历史，KineBench 类显式 3D evaluator 验证生成动作，SmartVL 类 budget controller 决定每轮用于观察、检索与推理的资源。关键不在模块叠加，而在为每个外部对象维护 provenance、置信度和失败恢复：错误 demonstration、错误 pose 或错误旧日志一旦被当成 ground truth，外部化只会让错误更持久。

## 方法谱系

| 路线 | 代表论文 | 核心假设 | 优势 | 局限 |
| --- | --- | --- | --- | --- |
| 原生空间控制 | Masked Visual Actions | 与预训练表示同空间的动作最容易迁移 | 跨 embodiment；同模型 forward/inverse | 隐式物理、部署仍需 mask/pose 管线 |
| 主动感知 | OmniReasoner | 关键证据稀疏，局部高保真胜过均匀采样 | 节省上下文；决策可解释为时间区间 | 错误定位会锁死；多证据聚合不足 |
| Agent + specialist tools | Agentic Real2Sim | VLM 擅长有界语义判断，专用工具擅长数值计算 | 可审计、可替换 backend、输出可执行状态 | 工具误差级联；Agent 增益未做消融 |
| 视觉生成 + bounded memory | AlayaWorld | 多尺度视觉记忆足以维持长时一致性 | constant context、回访一致、prompt/camera 控制 | 没有对象级状态与因果，所谓无限仅是可继续采样 |

## 当前共识

- **表示对齐比单纯堆模型更关键**：MVA 的像素动作、OmniReasoner 的绝对时间、AlayaWorld 的 camera pose / spatial warp 都把控制信号对齐到模型或工具的原生坐标系。
- **基础模型需要结构化外部机制**：mask、zoom tool、specialist simulator tools、显式 memory cache 都比“让模型自己在长上下文里学会一切”更可控。
- **短期连续性、长期记忆和物理状态必须分开评估**：视觉稳定不等于物理正确，replay 相似也不等于 intervention 正确。
- **当前证据多停留在代理任务**：视频相似度、VLM judge、benchmark consistency 和 replay keyframes 都不是完整真实世界闭环。

## 关键争议

### 1. 视频生成器是否已经是世界模型？

MVA 和 AlayaWorld 表明视频 prior 能提供有用的 motion/contact correlations；但 MVA 作者明确承认缺少 causal relationship，AlayaWorld 也承认不理解显式 object state、physical causality 和 long-term task structure。因此更准确的称呼是“可控 observation predictor”，除非论文证明 intervention、counterfactual 和隐藏状态一致性。

### 2. Agentic 是否带来真实增益？

Agentic Real2Sim 只比较 VLM backend，没有比较同工具下的固定规则或人工 pipeline。现有结果支持“小型 VLM 足以编排”，不支持“Agent 是成功率来源”。OmniReasoner 的消融更接近因果证据：移除 tool-return、tool-use data 或 TimeAnchor 都会下降。

### 3. 效率是否被完整核算？

OmniReasoner 未报告 zoom 后的额外帧/token/延迟；Agentic Real2Sim 只报模型 API bill；AlayaWorld 只报 30→4 steps 而没有 sec/chunk；MVA 的 15 小时数据需要约 8×H200×4 天训练。四篇都存在“局部效率指标替代端到端 TCO”的问题。

## 综合判断（个人推断）

更可信的下一代架构不会由其中一篇单独给出，而可能是四层组合：

1. 用 MVA 类原生视觉动作接口生成候选 future；
2. 用 OmniReasoner 类主动感知策略决定何时追加高保真观察或验证；
3. 用 Agentic Real2Sim 类工具链把关键状态投影到显式 simulator，检查接触和物理参数；
4. 用 AlayaWorld 类多尺度记忆维持视觉连续性和远距离回访。

关键不是把模块堆在一起，而是让每层输出可校准的不确定性，并在 observation predictor 与 physics simulator 不一致时触发验证。这个组合目前没有被四篇中的任何一篇直接验证。

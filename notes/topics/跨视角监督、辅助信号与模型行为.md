# 跨视角监督、辅助信号与模型行为

这组 2026-07-24 ArXiv 论文共同指向一个比“模型大小/数据量”更细的变量：同一底层任务，经过不同视图、奖励归一化、干预时机、几何表示或 residual channel 后，模型得到的学习信号并不等价。论文的证据强度差异很大，不能把它们的结果拼成一个统一因果定律。

## 横向结论

1. **表示/通道决定信号能否被正确消费。** MIRROR 的同题不同视图只有进入 teacher-student KL 才产生定向迁移；Dark Room 的同一 prediction signal 换成 mean-only 或 loss channel 后，结果从 collapse 变成 baseline/提升；3D-VLM 把显式坐标补给 implicit geometry，才改善定量空间任务；Misalignment 的 activation read channel 有效而 naive weight write edit 无效。
2. **“更多监督”不是单调好事。** Dark Room 的 dense reward 将 agent 推入 dark room；Overassist 的早介入提高当前题成功却没有短期泛化；MIRROR 只有把强视图与弱视图方向性关联后才超过 mixed GRPO。
3. **负控制比 headline 更重要。** MIRROR 需要 fixed-teacher、mixed-GRPO、EMA 和 compute-matched 对照；Dark Room 需要 mean-only、no-signal、decoupled、shuffle placebo；Misalignment 需要 matched-rank random、norm-matched random 和 read/write controls。3D-VLM 的 ablation 则显示 IGT、EGT、IEA 的增益层次。
4. **能力成本是核心边界。** Misalignment 的 activation projection 把 narrow adherence 从 0.902 降至 0；3D-VLM 的 geometry encoder 带来 6 vs. 7 FPS；MIRROR 多约 37.5% update FLOPs；Overassist 的帮助代价表现为用户推理机会与迁移不足。
5. **证据等级不能混用。** 3D-VLM 的多任务表格和组件消融较完整；MIRROR 的 ODA-Val 证据强但数据按不对称筛选；Dark Room 与 Misalignment 的代数/机制结果有启发性，但分别受单 seed/单模型、margin instrument 和 capability confound 限制；Overassist 的真实学习外推最弱。

## 统一分析框架

读这类论文时，优先问四个问题：

- **信号是什么**：最终答案、逐步预测、他视图的 token 分布、显式几何，还是 persona margin？
- **信号在哪里被消费**：GRPO reward、auxiliary loss、attention adapter、residual activation、weight gradient，还是用户 context？
- **负控制是什么**：去掉信号、打乱信号、换随机方向、固定 teacher、matched compute/数据是否仍保留效果？
- **代价是什么**：额外 FLOPs、延迟、能力损失、用户自主性、可迁移性和安全性是否被同时测量？

## 可复现与后续实验

- MIRROR：取消模态不对称预筛选；按相同 update FLOPs 比较 adaptive/fixed/mixed；扩展到图表和视频。
- Dark Room：至少 3 seeds、group-size sweep、critic PPO/Dr. GRPO 对照；完成 disjoint-vocabulary placebo 和 progress-style Δacc。
- Overassist：把 simulated student 换成真实学习者；从单个 variant 扩展到多题、延迟测验和多轮 tutor policy。
- 3D-VLM：加入 noisy depth/pose、动态/室外视频；拆出 AnySplat preprocessing cost；在 action grounding 上验证。
- Misalignment：跨模型/scale、base-to-alignment checkpoint extraction、usage-matched controls、capability-preserving read/write edit。
